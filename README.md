# 商業設立登記內容擷取
取出商業設立公文中名稱、地址、統編等資訊

## 用法
1. 選擇放置PDF的資料夾。
2. 執行程式開始分析。
3. 分析完成後輸出Excel，欄位包含編號、檔名、收文流水號、統一編號、場所名稱、備註等。
